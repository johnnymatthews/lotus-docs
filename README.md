# Lotus Docs

## Prerequisites

- [Hugo](https://gohugo.io/)

## Setup

1. Download this repo and move into it:

    ```shell
    git clone https://github.com/filecoin-project/lotus-docs
    cd lotus-docs
    ```

1. Initialize the Grundlagen theme submodule:

    ```shell
    git submodule add https://gitlab.com/johnnymatthews/grundlagen.git themes/grundlagen
    ```

1. Run the Hugo server:

    ```shell
    hugo server
    ```

1. Open [localhost:1313](http://localhost:1313) to view it.
1. Done.
